Inter (https://github.com/rsms/inter) and JetBrains Mono (https://github.com/JetBrains/JetBrainsMono), both under the SIL Open Font License 1.1, as packaged by Fontsource. Embedded in `library/lib/faces.ts` (a film's `kit/lib/faces.ts`), they make the older starters' sans and mono type draw the same on any machine; replace them with your own faces. The `app` starter's serif and the `screen-art` recipe's Georgia are not embedded and fall back where the face is not installed. Each licence text goes into a film's `kit/lib/` with the faces.
