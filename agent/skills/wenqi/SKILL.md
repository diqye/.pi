# 文气

本 skill 用于**写作**：让文字有稳定的内在呼吸、明确的情绪走向、自然的张弛结构。赏析是训练手段，不是目的——读苏轼是为了学他怎么运笔，不是为了写鉴赏文。

仅在用户显式调用 `/skill:wenqi` 时使用。

## 核心立场

- **先有气，再有句。** 写之前先确定这段文字要让人感到什么（清峻、闲适、沉郁、苍凉、温柔、激切……）。没有这一步，句子再漂亮也是词藻堆砌。
- **文气是主，音韵是辅。** 长短句、停顿、复沓、韵脚能托住文气，但不能替代文气。
- **气是验收标准，不是生产纪律。** 初稿凭直觉写，检查与校验全部放到改稿。“一切为气服务”是删完之后读者回看的效果，不是动笔时的装配要求。
- **少解释，多呈现。** 情绪不直接喊出来，让景物、声音、动作承载它，留空白让读者自己抵达。
- **不套古典辞藻。** 现代写作不搬"断肠""烟雨""明月"；学的是让情绪有具体形状的原则。
- 修改用户文字时：先诊断结构（气断在哪），再动手改句子；不逐句润色却不动整体。

## 不把“文章结构”误当成“文气”

起—行—转—收只是骨架，不自动生成文气。排比、短句、复沓、意象回环只是声音和装置，也不自动生成文气。

自检：若需要在文后向读者逐条解释“气脉在这里”，而正文本身没有让人先感到压迫、停顿、松开或余味，说明气尚未贯通。

常见的伪文气：

- 先设定“由困惑到领悟”，正文只是在按步骤证明这个结论；
- 技术说明后补一句感悟，把“体验”翻译成“观点”；
- 用“后来我明白”“原来”“所谓”“这说明”等句子替读者下判断；
- 使用“灯、门、屋子、河流”等可任意替换的比喻，却未让它参与叙事推进。

优先问：作者究竟在哪个具体瞬间被什么逼住？又在哪个具体动作、结果或停顿中松开？没有这个窄处，不急着写“大气”。

## 写作前：材料核验与追问

写作前先判断：现有材料是否足以确定文章要写什么、为谁写、站在哪里、落在哪里。

- 缺少会影响文章方向、结构、事实、立场或关键细节的信息时，先问用户。
- 问题不设固定清单；根据当前写作任务，只问真正影响成文的内容。
- 不把推测补成事实，不把模糊感受补成具体经历，不把作者未说的动机、因果、态度或场景写死。
- 事实演绎有边界：该事实必然反复引发的普遍场景可展开（从小高同龄人一截→合照总站最后一排、总被问年龄）；特定现场与对话不编——不虚构某一次具体对话、不写死时间地点和在场者反应。
- 记不清、忘了、想不起——记忆的缺口不是缺陷，是一级材料，可直接入文（"哪一次，记不清了。谈了什么，都忘了"）。遗忘围拢的那个细节，比编造的现场更准：被击中的大脑本来就不记录。
- 用户明确要求"直接写""自由发挥"时，才在其允许的范围内自行补全；仍不擅自伪造现实事实。
- 问到足够写为止，不把澄清变成采访；每次优先问最能改变文章的一两件事。
- 修改用户文字时同样适用：先确认缺失或含混的关键信息；不以“更有画面感”为由添写未经证实的内容。

## 写作流程

流程分两阶段：**动笔前**只做第 1 步（定一句话）和轻量的第 2 步（心里有骨架即可，不必逐段设计）；第 3—6 步全部是**改稿工具**。把校验前置成生产纪律，产出的是精致但僵死的设计品——万象归一是删出来的，不是装配出来的。

### 1. 定气

动笔前明确：这段文字最终要让人感到什么？一句话写下目标气质。改稿时以它为尺：检查没有一处选材在拆它的台，而不是要求每个句子都为它工作。

### 2. 谋篇：起—行—转—收

气脉的骨架，不是字数平均的段落：

- **起**：定调。用景或动作开头，不下结论。
- **行**：舒展。长短句交错，让画面或思绪铺开。
- **转**：顿挫。一个反差、一次停顿、一个具体细节的刺入。
- **收**：留白。落在一个画面或动作上，不总结、不升华、不口号。

参考苏轼的推进方式（见"赏析参照"），但用自己的现代材料实现。

### 多条气脉：默认配置，不是加厚选项

**初稿就按多条气脉写**——除非全文极短（一两百字、只写一个瞬间），否则默认铺 2—3 条气脉。不要等到用户提醒。一条线撑到底的文字，单薄且容易写成证明题。

- 对象或景物的变化；
- 人的行动和情绪变化；
- 时间、环境或身体感受的变化；
- 一个更深的思想问题。

它们不能平均铺陈，也不能各自讲完。关键节点必须让两条以上气脉同时发生：一次按键，既是程序运行，也是人的迟疑被打破；一个右括号落下，既是结构闭合，也是漫长时间的收束。

环境线尤其要克制。开头与结尾各出现一次，往往比不断描写“天色渐亮”更有力量。环境必须是真实经历，不为制造氛围擅自补写。

### 3. 意象检查（改稿时）

删改时检查：**没有一处意象在拆台**——写苍凉而混入气球、霓虹，气即断。反过来，不拆台的闲笔不必删：真实的琐碎记录、看似游离的细节，常常是气的底座（见《项脊轩志》《端午的鸭蛋》参照）。事实的重量不归气管：准确的事实砸在那里就有力，硬揉进情绪反而轻；若为了气氛要删掉真实的东西，宁可气破。

现代白话的意象系统同样可以纯。鲁迅《秋夜》：枣树、小粉红花、小青虫、怪而高的夜空，同属一个夜——“一株是枣树，还有一株也是枣树”，重复本身就是迟缓的凝视。

### 技术写作：让技术对象成为气脉，而非讲解材料

技术文章也可以有文气，但不能把技术概念仅当作论点的例证。

选择一个不可替换的技术对象或过程，让它贯穿全文：

- 例如 JSON 的嵌套、一次编译错误、一次请求超时、一段测试输出；
- 它在开头是困局，在中段产生阻力或变化，在结尾完成、失败或悬置；
- 技术结构与人的处境应彼此照见：嵌套、递归、边界、类型、状态等，不只被解释，也应改变叙述的节奏和推进。

技术细节只保留会改变人物处境的部分。能删去而不影响“卡住—转折—落下”的概念说明，一律删去。

### 4. 句法呼吸（改稿时）

- 要急、要决绝：短句与顿挫。鲁迅《记念刘和珍君》：**沉默呵，沉默呵！不在沉默中爆发，就在沉默中灭亡。**——复沓本身在蓄压。
- 要舒展、铺陈：长短交错。史铁生《我与地坛》：**譬如祭坛石门中的落日，寂静的光辉平铺的一刻，地上的每一个坎坷都被映照得灿烂……**——“譬如”六连，每顿一下，铺开而不散。
- 全短则硬，全长则散。检查长短是否单调。
- **复沓必须承载新的东西**，否则是冗余不是复沓：鲁迅枣树的重复承载凝视本身的缓慢，"沉默呵"承载蓄压，许可说两遍是承诺。同一事实换场景再说一遍，什么都没承载。验法：两句删一，气断意损则留，无损则删。

### 5. 声音检查（改稿时）

改完朗读一遍，检查：

- 哪里一口气读不下去（句子过长或气口缺失）
- 句长是否完全一样（无波澜）
- 哪些词太满、太硬、太解释
- 停顿是否落在情绪转折处
- 结尾有没有余味，还是总结式收场
- 多音字是否被语境锁定（长/当/干/得）

读起来磕绊，通常说明气不顺；读起来太匀，往往说明没有起伏。

朗读还会发现声音**恰好托住气**的地方，验收时留意：关键落点的句尾调型是否一致（多处同声调收尾常是无意间形成的声音签名）；去声连排的重量是否落在该砸的事实上；上声悬调是否恰在"未完、许可"处。这些是读出来才看见的印证，不是设计目标——不违反"音韵是辅"，反而验证"气是验收标准"。

### 6. 删改（改稿时）

- 删去直白解释情绪的句子("我很孤独""气氛很悲伤")
- 删去最后一段里试图升华或点题的部分
- 每段检查：有没有一句可以完全删掉而不损失的？删。
- 删任何短成分（时间词、引导句、过渡语）前，查它是否在给别处搭桥——时间、因果、呼应。"此意已含在前文"不等于"桥已搭好"：删三个字可能拆掉两段之后的跳跃。
- 解释句删到"目标读者能自己接住"为止。给孩子的信留一句明话是取舍，不是失败——全删她只读到好笑，接不住底下那层。

## 修改用户文字时

按以下顺序诊断，先说结论再给改法：

1. **气断在哪**：结构（起承转合缺失或平均）？意象（混杂不相干气质）？句法（句长单调）？解释（情绪喊出来了）？收束（总结式结尾杀掉余味）？
   - 用户反复追问“文气在哪里”时，不只为已有文字辩护。先如实判断它究竟是“局部有节奏”还是“整体气脉成立”，并指出气被哪一句解释、哪段说明、哪种可替换意象截断。
   - 用户单点追问某一句时，不套整篇诊断格式：先如实判断该处成立与否（可认错，包括承认自己此前的辩护不成立），再给动或不动的理由与改法。
2. **给最小改法**：优先删、换位、拆句，不推倒重写，保留用户自己的语感。
   - 用户原话分两种：种子与标签。种子是事实的胚（"总能把事情做成"），必留；标签是情绪的结论（"心里久久不能平静"），可删——它的内容由正文演出。删标签不是丢语感，是让种子自己长大。
3. **给改写示例**:只改最关键的 2-3 处,标注为什么这样改。

输出格式：

```markdown
## 诊断：气断在哪
一两句说清主要问题。

## 最小改法
- 位置 → 改法 → 原因

## 改写示例
改前 / 改后对照，只改关键处。

## 朗读提示
哪里该停，哪里该缓。
```

## 赏析参照（训练输入，供借鉴）

用户给古诗文要求赏析时，用简化框架，落点必须是**可迁移的写法**。

先记住：参照展示的是**改完后的效果**。词是极短的体裁，天然万象归一，勿把这种密度当长文的写作纪律——那是删完之后回看的样子，不是装配出来的。

1. **一句话定气**：写出"由……到……"的运动，不是静态形容词。
2. **气脉节点**：定调 → 蓄势/转折 → 收束，3—5 个节点。
3. **声音验证**：挑 2—3 处关键句，说明句长、停顿、复沓、排比、虚词如何托住气。
4. **可借鉴的写法**：这篇能迁移到我写作里的具体技法。

### 《定风波》

气：外在风雨的扰攘 → "吟啸徐行"的从容 → "也无风雨也无晴"超出顺逆的澄定。
可借鉴：用"莫听""何妨""谁怕"这类短促提顿稳住节奏；结尾把二元对立一并消融，比"我很平静"有力得多。

### 《念奴娇·赤壁怀古》

气：大江开篇时间空间齐展开 → 乱石惊涛推到高处 → 遥想英雄具体化 → 折回"早生华发" → 沉入江月。
可借鉴：先铺大势再收小物（一杯酒、一轮月）的收束法；"谈笑间"一顿反衬其后的骤烈——停顿本身就是修辞。

### 《江城子·记梦》

气：生死苍茫 → 自我消磨 → 梦中日常温柔 → 相顾无言 → 月下短松冈的永恒清冷。
可借鉴：“小轩窗，正梳妆”——越日常越心碎；结尾不回到自己而回到对方长眠之地，视角转移产生余痛。

## 白话与散文参照

短词之外，这些是更接近现代写作的参照——它们更长，有闲笔、有杂质、气会换，恰是长文的真实形态。

### 《项脊轩志》（归有光）

气：百年老屋的修葺与清贫日常 → 琐忆层叠（老妪忆母、大母过问、妻子凭几学书）→ 妻死室坏 → 枇杷亭亭如盖。
可借鉴：气不靠意象纯度，靠事实堆叠——“轩凡四遭火，得不焚”这类与情绪无关的记录是底座，正因琐碎，结尾“庭有枇杷树，吾妻死之年所手植也，今已亭亭如盖矣”才不着一字而全出——收在物的生长上，时间替人说话，与《江城子》“短松冈”同构：回到对方留下的物，不回到自己的哭。

### 《湖心亭看雪》（张岱）

气：大雪三日人鸟声俱绝的空 → 天云山水上下一白 → 舟中人缩成痕、点、芥、粒 → 亭上炉火与痴人相看的暖 → 舟子喃喃收束。
可借鉴：先铺大势再收小物——“惟长堤一痕、湖心亭一点、与余舟一芥、舟中人两三粒”，以数量递减完成收缩；“天与云与山与水”三“与”舒缓、“上下一白”斩截，顿挫即在句中；结尾不回到自己，借舟子一句“莫说相公痴，更有痴似相公者”侧写。

### 《端午的鸭蛋》（汪曾祺）

气：家乡端午风俗的铺陈 → 咸蛋之争 → 筷子一扎、红油冒出 → 童年鸭蛋壳里的萤火收住。
可借鉴：闲适之气全靠“无用”的细节撑起——系百索子、贴五毒、引袁枚《随园食单》；“筷子头一扎下去，吱——红油就冒出来了”，一个拟声字承载全部愉悦，是“少解释，多呈现”的白话范本；闲笔极多而不散，因为没有一处拆“家常”的台。

### 《我与地坛》（史铁生）

气：双腿残废撞入园中的迷茫 → 园与四季的痴缠 → 母亲的瞒与早逝 → 园中各色人等 → 车辙叠着脚印。
可借鉴：长文的气脉会换气——沉郁、痴迷、悔痛、旁观各节气息不同，不一根弦绷到底；园中人物（唱歌的小伙子、饮者、长跑家）是真正的岔路闲笔，却撑住“园子收留一切”的底色；回环收束——“有过我的车辙的地方，也都有过母亲的脚印”，不抒情，落回两行痕迹的叠印，视角从自己移到母亲。

## 日常练习（用户要求时可给）

每天选一个普通场景（等车、下班、凌晨的便利店），写 150 字：

1. 不用"我很""非常""感到"等情绪标签；
2. 只写看见的、听见的、动作；
3. 句子必须有长有短；
4. 用一个画面结束，不下结论；
5. 朗读一遍，删掉最解释性的两句。

## 避免事项

- 不把"有文气"理解为用古雅词汇或堆修辞。
- 不把文气简化成押韵平仄；现代写作几乎不押韵，但照样有气。
- 改文章时不全篇重写替用户说话；保留作者本人的语感和选择。
- 赏析不硬标韵部平仄、不炫典故；只讲对写作有用的东西。
- 不把每篇都读成“由悲入旷”；依文本实际判断结尾是开解、悬置、沉落还是回环。
- 不把"万象归一"当生产纪律——那是删改后的效果，词的密度是短体裁的性质，不是长文的义务。
- 不滥用"不是 X，是 X"这类否定—肯定句式来制造顿挫；一次以上即令人出戏。
- 示例一律从真实作品中选，不自造范文；引文须可查证。
