使用全局命令 `gpt-image-2` 生成图片。以下是用户的图片需求，需先理解并据此编写图片生成提示词：

$@

## 执行规则

1. 先根据用户需求自行编写清晰、具体的图片生成提示词；不要直接将 `$@` 原文作为 prompt 传入。然后用 bash 工具执行：
   ```
   gpt-image-2 "<优化后的图片提示词>" --out "<输出路径>"
   ```
   如果用户提供了参考图片，在命令末尾追加 `--ref "<参考图路径>"`（多张可重复传）。

2. **输出路径**：默认存到当前项目目录下。如果用户指定了文件名就用指定的，否则用 `./out-<简短描述>.png`。

3. **根据图片类型选择默认参数**（用户未明确指定时）：
   - 普通图片/插画：`--aspect 16:9`
   - 头像/图标：`--aspect 1:1`
   - 海报/竖图：`--aspect 9:16`

4. 命令执行完成后，读取生成的图片文件确认生成成功，并告诉用户图片保存路径。

5. **参考图/图生图**：用户给出图片路径/URL 并要求"参考、基于、改图、融合"时：
   - 本地路径 → `--ref <path>`（可多张）；远程 URL → `--ref-url <url>`
   - 此时 prompt 描述要改为编辑/融合指令（如"把背景换成森林"），而不是重新描述整张图
   - 参考图格式限 jpeg/jpg/png/webp，总量 ≤7MB；有参考图时 prompt 可省略

6. **局部重绘（--mask）**：用户只想改图中某块区域（如"只换天空、只换衣服"）时：
   - 用户提供了现成蒙版 → 直接 `--mask <path>`
   - 没提供 → **用 mask 子命令自行生成**（模型有语义理解，矩形近似 + 羽化即可，不必精确轮廓）：
     ```
     # 先用 read 工具看图估目标区域坐标，再画蒙版（自动读原图尺寸）
     gpt-image-2 mask --ref <原图> --rect 0,0,W,H顶部40% --blur 20 -o ./mask.png
     # 圆形区域（头像、太阳等）：
     gpt-image-2 mask --ref <原图> --circle cx,cy,r --blur 15 -o ./mask.png
     ```
   - 语义：涂的图形区域 = 允许重绘，黑色 = 保留原图；输出文件里重绘区存为透明（API 规范），预览中显示为白色属正常
   - 最后组合调用：`gpt-image-2 "<编辑指令>" --ref <原图> --mask ./mask.png`
   - mask 子命令纯本地执行、不消耗云 API 费用，可放心多试

## 可用选项（按需添加）

| 选项 | 说明 | 取值 |
|---|---|---|
| `--aspect, -a` | 宽高比 | 1:1 3:2 2:3 3:4 4:3 16:9 9:16 21:9 9:21 |
| `--resolution, -r` | 分辨率 | 1K 2K 4K（默认 1K） |
| `--format, -f` | 格式 | png / jpeg |
| `--count, -c` | 生成张数 | 1-8 |
| `--out, -o` | 输出路径 | 文件路径 |
| `--negative, -n` | 负向提示词 | 文本 |
| `--ref` | 本地参考图 | 文件路径，可重复 |
| `--ref-url` | 远程参考图 | URL，可重复 |
| `--mask` | 蒙版图（局部重绘） | 文件路径，配合 `--ref` |
| `--no-enhance` | 关闭提示词增强 | — |

### mask 子命令（生成蒙版，纯本地）

| 选项 | 说明 | 取值 |
|---|---|---|
| `--ref` | 读参考图尺寸（仅 PNG） | PNG 路径 |
| `--size` | 显式指定尺寸 | WxH，如 1536x1024 |
| `--rect` | 重绘矩形，可重复 | x,y,w,h |
| `--circle` | 重绘圆，可重复 | cx,cy,r |
| `--blur` | 边缘羽化，推荐 15~25 | 像素数 |
| `--out, -o` | 输出路径 | 默认 ./mask-<时间戳>.png |

## 提示词优化

根据用户需求补充必要细节，例如主体、风格、构图、色彩、光影、文字要求和负向约束，但不得改变用户核心意图。即使用户描述很详细，也应将其整理为适合图片模型的明确提示词，而非原样转发。
