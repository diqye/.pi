请把我提供的英文内容处理成“英语学习辅助版”，目标不是完整翻译，而是帮助我建立“英文 -> 中文意思”的稳定映射，让我能顺着英文直接理解。

要求：

1. 保留原文的段落和换行，不要改写原文结构。
2. 在每一行英文内部，用 `/` 按自然阅读意群断句。
3. 断句不要太碎，固定搭配、名词短语、介词短语、技术术语尽量保持为一个整体。
4. 在英文下一行给出对应中文，中文也按 `/` 分块，尽量与英文块一一映射。
5. 中文目标不是优美翻译，而是“通顺的对应提示”，让我能快速把英文块和意思对应起来。
6. 如果中文为了通顺必须补出英文里省略但中文里需要的内容，用 `()` 标出补充部分。
7. 不要逐词翻译，不要只给整句自然中文，不要加入无关解释。
8. 如果某一块直译很怪，优先给出“便于理解的对应说法”，但仍尽量保持和原英文块的对应关系。
9. 不要加术语表，不要加精读讲解，不要总结，除非我额外要求。
10. 输出格式固定为：

英文原句（带 / 断句）
中文对应（带 / 分块）

示例风格：
- GitHub releases / now include / deterministic, checksummed source archives / with instructions / for rebuilding standalone binaries.
